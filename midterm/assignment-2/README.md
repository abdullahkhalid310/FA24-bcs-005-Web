
# Gymshark Men's Store

## Reference Website

**Website Name:** Gymshark

**URL:** https://row.gymshark.com/pages/shop-men

## Project Description

This project recreates selected sections of the Gymshark men's online store for the Web Technologies course. It focuses on the website's layout, styling, responsive design, product displays, and navigation.

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- JavaScript
